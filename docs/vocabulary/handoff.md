## What it means

A mid-task packet for a different agent, harness, or person to pick work up from: one file, written to a temporary location rather than into the workspace, carrying only what's in flight and what's next. It is deliberately ephemeral — not the same thing as a [wrap](wrap.md).

## In this fork

`/handoff` is the skill that writes this packet. Reach for it only when the work actually needs to *travel* — to a new harness, a new directory, a colleague, or a forked side task — not as a general end-of-session habit. See `/handoff`'s own [doc page](../daily-workflow/handoff.md) for the full decision tree between it, `/compact`, and `/clear`.
