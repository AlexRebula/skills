## What this is

A handful of words this fork uses on purpose: skill, flow, harness, router, bootstrap, handoff, and wrap. Each has its own short, ELI5-level page here. The reasoning for why the split matters at all lives on [Skills, flows, and harnesses](../skills-flows-harnesses.md); this index is the fast lookup, not the argument.

## Terms

- **[Skill](skill.md)** — one packaged procedure.
- **[Flow](flow.md)** — a composed path through skills.
- **[Harness](harness.md)** — the runtime this pack installs into.
- **[Router](router.md)** — the one skill that names all the others.
- **[Bootstrap](bootstrap.md)** — what loads before any of this is useful.
- **[Handoff](handoff.md)** — a mid-task packet for a different agent, harness, or person.
- **[Wrap](wrap.md)** — the permanent record a session leaves behind.
